# 🚀 Быстрый старт

## 1. Запуск системы

```bash
./start.sh
```

Или вручную:
```bash
docker compose up -d
```

**⚠️ ВАЖНО:** После установки Docker нужно перелогиниться или выполнить:
```bash
newgrp docker
```

## 2. Загрузка моделей (обязательно!)

После запуска контейнеров выполните:

```bash
# Загрузка основной модели (выберите одну)
docker exec -it ollama ollama pull qwen2.5:7b      # Рекомендуется - быстрая, ~5GB
# ИЛИ
docker exec -it ollama ollama pull qwen2.5:14b     # Лучшее качество, ~9GB

# Загрузка модели для работы с документами (обязательно!)
docker exec -it ollama ollama pull nomic-embed-text
```

Загрузка может занять 5-15 минут в зависимости от скорости интернета.

## 3. Доступ к системе

Откройте браузер: **http://localhost:3000**

### Первый вход:
1. Нажмите **Sign up**
2. Создайте учетную запись администратора
3. Войдите в систему
4. В выпадающем списке выберите модель (например, `qwen2.5:7b`)
5. Начните чат!

## 4. Загрузка документов компании

### Через веб-интерфейс:
1. Нажмите на иконку с шестеренкой (Settings)
2. Перейдите в **Workspace** → **Documents**
3. Нажмите **+** и загрузите документы
4. В новом чате нажмите **+** → **#** → выберите документы
5. Задавайте вопросы по документам!

### Через папку:
```bash
cp ваши-документы.pdf ./documents/
```

## 5. Проверка работы GPU

```bash
nvidia-smi
# Или постоянный мониторинг:
watch -n 1 nvidia-smi
```

## 6. Доступ из локальной сети

Узнайте IP-адрес сервера:
```bash
hostname -I
```

Пользователи смогут подключиться: `http://<IP-адрес>:3000`

## 7. Управление системой

```bash
# Просмотр логов
docker compose logs -f

# Остановка
./stop.sh
# или
docker compose stop

# Перезапуск
docker compose restart

# Проверка статуса
docker compose ps
```

## 🆘 Решение проблем

### Permission denied при запуске Docker

```bash
# Добавить пользователя в группу docker (уже выполнено)
sudo usermod -aG docker $USER

# Применить изменения без перезагрузки
newgrp docker

# Или перелогиниться
```

### Контейнеры не запускаются

```bash
# Проверить логи
docker compose logs

# Пересоздать контейнеры
docker compose down
docker compose up -d
```

### Модель не отвечает или медленно работает

1. Проверьте, что модель загружена: `docker exec -it ollama ollama list`
2. Проверьте GPU: `nvidia-smi`
3. Попробуйте меньшую модель: `qwen2.5:7b`

### Open WebUI показывает ошибку подключения

```bash
# Проверьте, что Ollama запущен
docker compose ps

# Перезапустите сервисы
docker compose restart
```

## 💡 Советы

1. **Первый запуск занимает время** - Docker скачивает образы (~2-3 GB)
2. **Загрузка моделей** - обязательный шаг, без моделей система не работает
3. **Используйте qwen2.5:7b** для начала - оптимальный баланс скорости и качества
4. **Для документов обязательно** загрузите `nomic-embed-text`
5. **История чатов сохраняется** - даже после перезапуска
