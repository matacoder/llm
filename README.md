# Локальная LLM система (PoC)

Полностью локальное решение на базе Ollama и Open WebUI с интерфейсом как ChatGPT.

## 🚀 Возможности

- ✅ Веб-интерфейс как ChatGPT
- ✅ Работа с документами (RAG)
- ✅ Поддержка русского и английского языков
- ✅ Мультиюзерная система с историей чатов
- ✅ Работает полностью локально (без интернета)
- ✅ Использует NVIDIA GPU
- ✅ Доступен только в локальной сети

## 📋 Требования

- Linux (протестировано на Ubuntu/Mint)
- Docker и Docker Compose
- NVIDIA GPU с CUDA (рекомендуется 16GB+ VRAM)
- NVIDIA Container Toolkit

## 🛠 Быстрый старт

### 1. Запуск системы

```bash
./start.sh
# или напрямую:
docker compose up -d
```

Проверка статуса:
```bash
docker compose ps
docker compose logs -f
```

### 2. Загрузка моделей

После запуска контейнеров загрузите LLM модели:

```bash
# Загрузка основной модели (Qwen 2.5 7B - отличное качество для русского)
docker exec -it ollama ollama pull qwen2.5:7b

# Или более мощная модель (Qwen 2.5 14B - лучшее качество, ~9GB VRAM)
docker exec -it ollama ollama pull qwen2.5:14b

# Загрузка модели для эмбеддингов документов (обязательно для RAG)
docker exec -it ollama ollama pull nomic-embed-text
```

### 3. Доступ к системе

Откройте в браузере: **http://localhost:3000**

При первом входе:
1. Создайте учетную запись администратора
2. Войдите в систему
3. Выберите модель в выпадающем списке (qwen2.5:7b)

## 📚 Работа с документами компании

### Загрузка документов для RAG

Есть два способа:

#### Способ 1: Через веб-интерфейс (рекомендуется)

1. В Open WebUI перейдите в **Settings** → **Documents**
2. Нажмите **Upload Files**
3. Загрузите документы (PDF, DOCX, TXT, MD и др.)
4. Документы автоматически индексируются

#### Способ 2: Через папку

Скопируйте документы в папку:
```bash
cp /путь/к/документам/* ./documents/
```

Затем в чате включите **Document Search** и загрузите их через интерфейс.

### Использование RAG в чате

1. Создайте новый чат
2. Нажмите на иконку **"+"** рядом с полем ввода
3. Выберите **Documents**
4. Выберите нужные документы
5. Задавайте вопросы - LLM будет использовать контекст из документов

## 🌐 Доступ из локальной сети

### Узнать IP-адрес сервера

```bash
ip addr show | grep inet
```

### Настройка доступа

Пользователи в локальной сети смогут подключиться по адресу:
```
http://<IP-адрес-сервера>:3000
```

Например: `http://192.168.x.x:3000`

### Ограничение доступа только локальной сети

В `docker-compose.yml` порты уже настроены на `0.0.0.0:3000`, что означает доступ из локальной сети.

Для дополнительной безопасности можно настроить firewall:

```bash
# Разрешить доступ только из локальной сети (замените на вашу подсеть)
sudo ufw allow from 192.168.0.0/16 to any port 3000
sudo ufw enable
```

## 🐛 Решение проблем

### Контейнер не запускается

```bash
# Проверить логи
docker compose logs

# Пересоздать контейнеры
docker compose down
docker compose up -d
```

### GPU не используется

```bash
# Проверить NVIDIA Container Toolkit
docker run --rm --gpus all nvidia/cuda:12.0-base nvidia-smi

# Если не работает, переконфигурировать
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

### Open WebUI не видит Ollama

```bash
# Проверить, что Ollama работает
docker exec -it ollama ollama list

# Проверить сетевое подключение
docker compose exec open-webui curl http://ollama:11434
```

### Медленная работа

1. Используйте меньшую модель (qwen2.5:7b вместо 14b)
2. Проверьте загрузку GPU: `nvidia-smi`
3. Убедитесь, что другие процессы не используют GPU
